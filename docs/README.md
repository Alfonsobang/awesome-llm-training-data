# Project Pages

This directory is now organized as a portfolio of practical pages, not only a resource archive.

The project still has one core direction: public-safe financial agent evaluation. The supporting pages create multiple ways for people to discover, reuse, and extend the work.

## Core Direction

- [Financial Agent Evaluation Positioning Thesis](financial-agent-eval-positioning.md) - Why this project should focus on auditable financial-agent tool-use evaluation instead of another generic awesome list.
- [FinAgentBench Seed Spec](finagentbench-seed-spec.md) - Proposed shape of the runnable benchmark seed.
- [Financial Agent Evaluation Agenda](financial-agent-evaluation-agenda.md) - Topic map for search, lookup, filing QA, backtesting, forecasting, compliance, and evidence-grounded agent evaluation.
- [Financial Agent Evaluation Roadmap](financial-agent-evaluation-roadmap.md) - Longer project direction for the finance track.

## Multi-Track Pages

- [Financial Agent Failure Gallery](financial-agent-failure-gallery.md) - Common failure modes that static QA misses.
- [Financial RAG Evaluation Playbook](financial-rag-evaluation-playbook.md) - How to evaluate retrieval, citation, extraction, and answer faithfulness in finance workflows.
- [Financial Data Governance Control Plane](financial-data-governance-control-plane.md) - A public-safe governance model for sources, licenses, cutoffs, and redistribution boundaries.
- [Synthetic Financial Evaluation Data Playbook](synthetic-financial-evaluation-data-playbook.md) - How to use synthetic fixtures without creating fake realism or trading claims.
- [Annotation and Preference Quality for Finance](annotation-preference-quality-for-finance.md) - Quality controls for finance-specific human feedback, preference data, and adjudication.
- [Agent Benchmark Lessons](agent-benchmark-lessons.md) - What this project should learn from SWE-bench, WebArena, OSWorld, and FinanceBench.

## What Not To Add

- Private company data.
- Real user data.
- Proprietary workflows.
- Investment advice or trading signals.
- Broad AI trend commentary without runnable or reusable artifacts.
